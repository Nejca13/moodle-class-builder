Introducción a Python

Introducción

Python es un lenguaje de programación interpretado, de alto nivel y fácil de leer. Se utiliza en scripting, web, datos e IA.

Objetivos

  • Comprender la sintaxis básica
  • Crear variables y funciones
  • Resolver problemas simples

Contenidos

Tipos de datos, estructuras de control, funciones y módulos.

Desarrollo

Escribimos un programa que saluda al usuario y suma dos números ingresados por teclado.

Conceptos clave

  • Variable
  • Función
  • Tipo de dato

Ejemplo

print("Hola, mundo")

Actividad propuesta

Creá un programa que calcule el área de un triángulo.

Cierre

Python permite pasar de la idea al código con muy pocas líneas.
