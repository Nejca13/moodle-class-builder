API REST con FastAPI

Contexto

En la materia de Programación vamos a construir servicios web pequeños y autónomos.

Objetivo

Crear una API REST básica utilizando FastAPI.

Consigna

Desarrollar una API que permita listar y crear tareas, persistiendo en memoria.

Pasos / instrucciones

  1. Crear proyecto y entorno virtual
  2. Crear endpoint GET /tareas
  3. Implementar validación con Pydantic
  4. Probar mediante Swagger (docs)

Recursos necesarios

  • Editor de código (VS Code)
  • Python 3.11+
  • Navegador web

Entregable

Repositorio con el código y un video corto de la API funcionando.
